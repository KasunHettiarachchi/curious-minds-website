# Development Phases

## Phase 1: Foundation
Next.js, TypeScript, Tailwind, layout, navigation, footer, responsive design, dark mode.

## Phase 2: Content
MDX support, article pages, category pages, cards, tags, related articles.

## Phase 3: Discovery
Search, filtering, featured articles, popular articles, related content.

## Phase 4: Interactive Engine
Reusable simulation containers, controls, sliders, Canvas, SVG, Three.js, D3.js.

## Phase 5: First Simulations
1. Projectile motion
2. Planetary orbit
3. Function graph
4. Probability simulation
5. Wave visualization

## Phase 6: SEO
Metadata, sitemap, robots, structured data, Open Graph, internal linking.

## Phase 7: Content
Create the first 20 high-quality articles.

## Phase 8: GitHub Pages
Static export, GitHub Actions, GitHub Pages deployment.

## Phase 9: Quality
Test mobile, desktop, accessibility, performance, SEO, broken links, and simulation usability.

## Phase 10: Future
Only after the website is established consider AI assistant, newsletter, analytics, user accounts, premium content, external APIs, backend, or database.
