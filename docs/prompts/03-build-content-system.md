# Prompt 03: Build Content System

Read:
- `/AGENTS.md`
- `/docs/05-content-system.md`
- `/docs/03-architecture.md`

Implement the MDX content system.

Requirements:
- Store articles in the repository.
- Support frontmatter.
- Generate article pages statically.
- Generate category pages.
- Generate article metadata.
- Generate related articles.
- Support KaTeX equations.
- Support embedding React components inside articles.

Create reusable article components for headings, paragraphs, images, equations, callouts, tables, and interactive components.

Create three realistic example articles:
1. Why Doesn't the Moon Fall Into Earth?
2. What Happens Near a Black Hole?
3. Why Is Pi So Important?

Do not use a database or external CMS.

Run all checks.
