# Prompt 04: Build Search

Read:
- `/AGENTS.md`
- `/docs/03-architecture.md`

Implement static-site search.

Requirements:
- No backend.
- No database.
- No external search service.

Generate a searchable article index during the build.

Support searching by:
- Title
- Description
- Category
- Tags

The search UI must work on mobile, show results immediately, handle no results gracefully, and link directly to articles.

Keep the implementation lightweight.
