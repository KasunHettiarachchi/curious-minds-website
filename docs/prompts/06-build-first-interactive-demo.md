# Prompt 06: Build First Interactive Demonstrations

Read:
- `/AGENTS.md`
- `/docs/06-interactive-system.md`
- `/docs/05-content-system.md`

Implement five high-quality interactive demonstrations.

### 1. Projectile Motion
Controls:
- Initial velocity
- Launch angle
- Gravity

Show:
- Trajectory
- Maximum height
- Range
- Flight time

### 2. Orbital Motion
Create an educational 2D orbital simulation.

Controls:
- Initial velocity
- Planet mass
- Starting distance

Show orbit, escape trajectory, and collision trajectory where appropriate.

Clearly label it as a simplified educational model.

### 3. Function Explorer
Allow users to explore mathematical functions with graph, axes, current values, and adjustable parameters.

### 4. Probability Simulation
Create an interactive probability experiment such as coin flipping or dice rolling. Let users increase trials and observe experimental probability.

### 5. Wave Visualization
Controls:
- Amplitude
- Frequency
- Wavelength

Show how the wave changes.

All simulations must work on mobile, have accessible controls, support reset, run client-side, and require no backend.

Use appropriate technologies rather than forcing everything into Three.js.
