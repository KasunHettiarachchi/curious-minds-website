Initialize the Curious Minds project.

Requirements:
- Next.js
- React
- TypeScript
- Tailwind CSS
- App Router
- Static export
- GitHub Pages compatibility

Do not add a database, backend, authentication, payment system, AI API, or Vercel-specific functionality.

Create a clean, scalable project structure.

Before changing files, inspect the repository.

After implementation:
1. Run TypeScript checks.
2. Run linting.
3. Run the production build.
4. Fix all errors.
5. Explain the resulting project structure.
