# Technology Stack

## Frontend
Next.js with React and TypeScript using the App Router.

## Styling
Tailwind CSS. Use shadcn/ui selectively.

## Content
MDX files stored in the Git repository.

## Animation
Framer Motion for page transitions, reveals, and meaningful micro-interactions.

## 2D Visualization
Use D3.js when complex data visualization is required. Use native SVG or Canvas when D3 is unnecessary.

## 3D Visualization
Use Three.js and React Three Fiber when 3D genuinely improves understanding.

## Mathematics
Use KaTeX for mathematical notation.

## Storage
No database initially. No external CMS. No backend initially.

## Hosting
GitHub Pages.

## CI/CD
GitHub Actions builds and deploys the static website.

## External Services
Avoid external services unless absolutely necessary. The initial website should work without external APIs.
