# Design System

## Visual Direction
The website should feel like a combination of:
- Modern science publication
- Digital museum
- Educational platform
- Scientific visualization laboratory

Avoid generic SaaS styling, excessive gradients, generic AI aesthetics, excessive glassmorphism, and clutter.

## Typography
Prioritize readability. Use a strong display style for major headings and a highly readable article font.

## Layout
Use generous whitespace. Articles should have a comfortable reading width. Interactive visualizations may use wider layouts.

## Dark Mode
Dark mode is the primary visual experience. Support light mode if practical.

## Animation
Animations should communicate relationships or provide visual feedback. Avoid decoration-only animation.

## Components
Create consistent buttons, cards, tags, navigation, article metadata, callouts, interactive controls, sliders, and tooltips.

## Mobile
Every interactive component must be usable on mobile and should not rely exclusively on hover.
