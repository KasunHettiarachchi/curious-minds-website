# SEO Requirements

Every article should have:
- Unique title
- Meta description
- Canonical URL
- Open Graph metadata
- Appropriate heading hierarchy
- Descriptive URL
- Structured data where appropriate

## URLs
Use readable URLs such as:
- `/space/why-does-the-moon-not-fall`
- `/physics/what-is-time-dilation`
- `/mathematics/why-is-pi-everywhere`
- `/computer-science/how-does-dns-work`

## Sitemap
Generate a sitemap during the build.

## Robots
Generate an appropriate robots.txt.

## Internal Linking
Articles should link to related articles.

## Performance
Optimize images, JavaScript bundles, fonts, lazy loading, and interactive components. Avoid loading large visualization libraries globally.
