# Project Overview

## Name
Curious Minds

## Purpose
Curious Minds is an interactive science and technology publication.

It explains difficult and fascinating concepts through:
- Articles
- Visual explanations
- Interactive simulations
- Mathematical visualizations
- Animations
- Diagrams

## Categories
- Space
- Physics
- Mathematics
- Computer Science
- Nature

## Core Product Idea
A normal article is:

> Read → Finish

A Curious Minds article is:

> Read → Understand → Experiment → Discover

Interactive content is a core feature, not merely decoration.

## Target Audience
Curious people who enjoy learning but do not necessarily have advanced scientific backgrounds.

## Content Style
Articles should be:
- Curious
- Clear
- Accurate
- Engaging
- Visual
- Concise where possible

Avoid academic-paper writing unless specifically required.
